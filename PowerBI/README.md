# Healthcare Power BI Dashboard

## Project Overview

An interactive healthcare analytics dashboard created using a synthetic dataset of 1,000 patients.

## Dashboard Features

- Total patient count
- Patients by department
- Top diagnoses
- Gender distribution
- Age-group analysis
- Healthcare KPIs
- Interactive visualizations

## Tools Used

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Modeling
- DAX
- Data Visualization

## Objective

To transform healthcare data into an interactive dashboard that helps users understand patient demographics, departments and diagnoses.

## Dataset

Synthetic healthcare dataset containing 1,000 patient records.
