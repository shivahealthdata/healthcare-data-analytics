# Healthcare Data Analytics Portfolio

## Project Overview

This project demonstrates healthcare data analysis using a synthetic dataset of 1,000 patients.

## Tools Used

- Microsoft Excel
- SQL
- Microsoft Power BI
- Data Cleaning
- Data Visualization
- Healthcare Analytics

## Projects

### Excel Healthcare Analytics
Healthcare dataset cleaning, analysis, pivot tables, charts, dashboard, insights and recommendations.

### SQL Healthcare Analysis
SQL queries designed to analyze patient demographics, departments, diagnoses and healthcare metrics.

### Power BI Healthcare Dashboard
Interactive dashboard created to visualize healthcare KPIs, patient demographics, departments and diagnoses.
