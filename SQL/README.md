# Healthcare SQL Analysis

## Project Overview

This project demonstrates SQL-based analysis of a synthetic healthcare dataset containing 1,000 patient records.

## Analysis Performed

- Total patient count
- Gender distribution
- Department-wise patient count
- Top diagnoses
- Average patient age
- Patient age-group analysis

## SQL Skills Demonstrated

- SELECT
- COUNT()
- AVG()
- GROUP BY
- ORDER BY
- CASE statements
- Aggregate functions
- Healthcare data analysis

## Dataset

The analysis uses a synthetic 1,000-patient healthcare dataset created for portfolio and learning purposes.

## Objective

To demonstrate the ability to transform healthcare data into meaningful insights using SQL.
